# REAS template — public or human-maintained project

Favor pragmatic ports and adapters. Make the composition root visible. Use named port traits and concrete adapter implementations. Make an operation easy to trace from inbound adapter to use case to concrete output.

Use domain types and explicit state transitions for invariants. Compile in small increments. Document decisions and operating procedures in OKF concepts, targeting ASD-STE100 without unverified compliance claims.
